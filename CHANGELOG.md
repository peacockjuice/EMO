# EMO release notes

## 0.2 — 2026-11-18

- BB session notices for questions, unread replies, and errors, with project selection and session exclusions.
- BB mode at power-on and restart. Manual modes remain available from the web panel.
- Faster scrolling labels, with the existing pause and card timing preserved.
- Character modes, six scenes, and a short tour of all animations.
- Signed Wi-Fi application updates with trial boot, confirmation, and rollback.
- A smaller application bundle and simpler reminder history handling.
- A product README with light and dark covers, an actual-renderer demo, project diagrams, and a build guide.

The project version is **0.2**; the BB plugin package uses **0.2.0**. Earlier working labels `0.3-dev` and `0.4-dev` refer to development checkpoints included in this release. Historical reports keep their original labels and build hashes. The original `v0.1` tag is unchanged.

This source release does not install an update on an existing device or reload a running BB plugin. See the [build and update guide](docs/build.md).

EMO remains a DIY prototype. Hardware results cover the runs described in their reports; long-term reliability and the deferred 30-minute auto soak remain unverified. The project license and third-party permissions remain unresolved. See [security status](SECURITY.md) and [credits](docs/credits.md).
